# mirror

Public mirror of files that are hard to download from some networks.
Each file is published as a GitHub Release asset; the release notes carry the
source URL and the SHA-256 checksum. Verify the checksum after downloading.

‏آینه‌ای عمومی از فایل‌هایی که دانلودشان از بعضی شبکه‌ها سخت است. هر فایل به‌صورت
‏یک Release منتشر می‌شود و آدرس منبع و هش SHA-256 آن در یادداشت همان Release آمده است.
