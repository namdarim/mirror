# mirror

Public mirror of files that are hard to download from some networks.
Each file is published as a GitHub Release; the release notes carry the source
URL, the SHA-256 checksum and, for split files, how to join the parts.
Verify the checksum after downloading.

‏آینه‌ای عمومی از فایل‌هایی که دانلودشان از بعضی شبکه‌ها سخت است. هر فایل به‌صورت
‏یک Release منتشر می‌شود و آدرس منبع، هش SHA-256 و (برای فایل‌های تکه‌شده) روش
‏چسباندن تکه‌ها در یادداشت همان Release آمده است.
